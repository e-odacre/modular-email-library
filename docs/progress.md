# Session progress

Keep a dated progress record for each working session in this folder. Use
`YYYY-MM-DD.md`; append a separate session section when multiple sessions happen
on the same day. Add each new entry to this index.

Each record should capture the objective, completed changes, decisions, checks
actually run, commit references, remaining limitations, and the next starting
point. Distinguish completed work from planned work and local commits from
published changes. Never include credentials or environment secrets.
